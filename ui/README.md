# User Interface Plan & Architecture

This directory contains the chat interface placeholder for the Smart Virtual Assistant.

## Technology Stack
- Target framework: Streamlit
- Mockup reference: Located at docs/ui_mockup.md

## How UI Calls the Backend
1. User enters question into input box.
2. UI invokes core assistant engine via Python module imports (or POST /query).
3. Assistant response is displayed in the chat view.
